# СУПЕРЛЕСТНИЦА — демо-макет сайта производителя лестниц (Минск)

Интерактивный демо-макет в стиле «сайт из вирусных рилс»: 3D-лестница собирается по мере скролла. Бесплатный макет-крючок для клиента (производитель лестниц, Минск).

## Что внутри
- Three.js (r128): процедурная лестница — 16 ступеней, косоуры, балясины, растущий поручень (drawRange)
- Камера летит по CatmullRom-кривой вокруг марша, scrub по общему прогрессу страницы
- Появление ступеней последовательно по прогрессу скролла, «монтаж» с лёгким овер-шутом
- Студийный свет (тёплая ключевая + холодная контровая), тени PCFSoft, туман, пылинки в луче, film grain
- GSAP + ScrollTrigger + Lenis, HUD стадий сборки, preloader с процентами
- Ноль внешних ассетов: модели процедурные, шрифты Google Fonts, CDN-библиотеки

## Стек
Three.js · GSAP + ScrollTrigger · Lenis · чистый HTML/CSS/JS. Хостинг GitHub Pages — $0.

## Запуск
Статика: открыть index.html или задеплоить на любой статик-хостинг.
